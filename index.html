Google Drive Sync

All your data is written to CineInvoice-Data.xlsx in your Google Drive. Every save writes to it, every app open reads from it.

One-time setup: go to Google Cloud Console → create OAuth 2.0 Client ID (Web application) → add this page's URL to Authorized JavaScript origins → paste the Client ID here. Enable the Google Drive API in the same project.
Confirmed jobs show as regular events; inquiries appear as tentative/transparent (they don't block other calendar users). Edits or deletions made directly in Google Calendar flow back into CineInvoice on next pull (app open + tab focus).
